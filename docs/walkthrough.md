# Short project walkthrough

The repository includes a silent demo walkthrough and labeled screenshots. They show fictional local data, never a real-domain validation result. Use this sequence to record your own narrated version after completing the exercises.

[Watch the silent demo walkthrough](media/walkthrough.mp4)

1. **Overview:** explain that Java provides a local management dashboard. Identify Demo or LDAP mode. Show the users, groups, OUs and lock count.
2. **Help desk tickets:** introduce onboarding, account recovery, department transfer and offboarding. Checks are derived from state and saved successful operations.
3. **Account tools:** show separate password reset/unlock operations, moving a user and disabling an account. Avoid displaying or recording passwords.
4. **Saved activity:** show a success and a rejected/failed action, filtering outcomes and explaining STARTED/PARTIAL records.
5. **Results:** download the mode-labeled Markdown report and event CSV. Explain the remaining real Windows checks.

For a real-domain recording, add ADUC verification and the actual denied/allowed/denied shared-folder tests. Keep generated report files private until reviewed and redacted. A simulator video should never be labeled as a successful Windows domain demonstration.
